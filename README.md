# TJ Class Schedule

面向同济学生的 Android 本地课程表。支持从同济 1 系统直接读取个人课表，也支持 CSV、XLSX、图片识别和手工添加课程。

> 非同济大学官方应用。本项目不会代表学校提供服务，请以学校教务通知和实际教学安排为准。

## 主要功能

公开源码中的排课测试使用虚构姓名、编号、课程和地点，仅用于验证解析格式。

- 在应用内完成同济统一认证，并从个人课表页面读取课程
- 使用桌面网页模式，改善手机端课表显示不完整的问题
- 只解析课表区域中的真实课程卡片，并按星期、节次排序
- 支持 CSV、XLSX 和常见图片格式导入，识别错误可在预览中修正或删除
- 支持单双周、不连续周次、多地点和一门课多个时间段
- 今日课表、本周课表、快速切换教学周和下一节课倒计时
- 国家法定节假日不显示课程；调休补班日可指定目标教学周和星期
- 本地精确通知、可调提前时间、三档声音/震动模式和锁屏课程提示
- 荣耀、华为、小米、OPPO、vivo 等国产 Android 后台设置说明
- 桌面小组件显示下一节课、时间、地点、教师和倒计时
- 长按课程卡片修改，支持单日临时停课、删除确认和时间冲突检测
- 导入前差异统计、合并或替换、撤销导入，以及本地 JSON 备份恢复
- 原生作业管理、课程筛选、截止倒计时和完成标记，课表右上角快捷进入
- 课表右上角定位按钮：离线保存多个定位点，显示米数与动态方向，可切换箭头/高亮并长按删除
- Canvas 与好课官方登录、Token 导入教程及凭证失效恢复；好课配对凭证续期
- 好课账号密码自动同步：用户明确同意后本机加密保存，票据失效时自动重登，验证码或密码拒绝时停止自动尝试
- 卓越星官方网页登录后自动接入已报名活动，按真实日期同步为课表备忘录，并更新提醒与桌面小组件
- 自动后台同步、作业变化提醒、每轮失效仅提醒一次；手动刷新不受自动间隔限制
- 可选作业截止提醒、通知测试及桌面作业倒计时小组件

## 隐私说明

- 课程、学期、设置和临时停课数据保存在设备本地 SQLite 数据库中。
- 不提供账号体系、云同步、统计 SDK 或广告 SDK。
- 网络用于同济 1 系统、法定节假日信息，以及用户接入的 Canvas、好课等平台。开启自动同步后也会在后台访问对应平台。
- 作业保存在本机 SQLite；平台凭证保存在系统安全存储中，不上传到开发者服务器，断开平台连接不会删除已同步作业。
- 用户主动提供的好课账号密码仅在本机加密保存，并只向好课官方账号中心提交，不包含在系统或课表 JSON 备份中。关闭自动同步后不自动重登，断开好课连接会删除保存的密码。
- 卓越星令牌由用户在官方页面登录后读取并加密保存；同步安排以平台为准，断开连接保留已同步活动。
- 定位点和方向模式保存在独立的本机数据库，仅保存或寻找时使用前台定位与方向传感器；退出或后台停止采样，不上传位置。定位点不包含在课表 JSON 备份或 Android 系统备份中。
- 统一认证在 WebView 中完成；应用不会把密码上传到开发者服务器。
- 清除应用数据或卸载前，建议先在“备份与恢复”中导出 JSON 备份。

更完整的说明见 [PRIVACY.md](PRIVACY.md)。

## 本地运行

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

构建 APK：

```bash
flutter build apk --release --target-platform android-arm64 --split-per-abi
```

构建产物位于 `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk`。此安装包仅支持当前主流的 64 位 ARM 安卓设备，不支持 32 位设备或 x86 模拟器。

## 测试

Canvas 自动续期入口：作业 → 平台连接 → Canvas → 自动续期设置。在课表内完成学校登录，创建或选择一枚仅供课表使用的专用令牌，勾选同意后开启。重新生成会使所选令牌旧值失效。后台执行受系统省电影响，学校要求人工认证时仍需重新登录；独立测试 App 的登录状态不会转移。

好课定期登录：在“作业 → 平台连接”连接好课并开启自动同步，后台约每 15 分钟使用已加密保存的 token、ticket 调用好课官方免密码登录接口。作业约每 30 分钟读取；失败时保留已有作业并在连接页提示，权限或账号异常时暂停维护，需更新连接。系统省电可能推迟运行，不能保证永久免登录。

轮换脚本回归：`node --test test/canvas_rotation_test.cjs`。本地 Android 插件位于 `packages/canvas_session_bridge`，前台和 Workmanager 后台共用同一本机加密状态，实际作业读取继续使用原平台客户端。

项目包含周次解析、节假日、调休、课程冲突、导入、数据库、通知规划和主要界面的自动化测试：

```bash
flutter test
```
